# MemeVerse Android Application

MemeVerse Android is the mobile application version of the MemeVerse platform. It connects to the MemeVerse PHP and MySQL web API, allowing users to log in, browse meme posts, view content, and interact with the platform through a mobile interface.

## Features

- User login and registration
- Home feed for browsing memes
- Connects to PHP/MySQL backend API
- Displays posts from the web application
- Image loading using Glide
- API communication using Retrofit and OkHttp
- Notification and unread count API support
- Mobile UI built with Android XML layouts
- Prepared for future features such as voting, comments, upload, profile, and messaging

## Technologies Used

- Java
- Android Studio
- XML Layouts
- Retrofit
- OkHttp
- Glide
- CircleImageView
- PHP/MySQL API backend

## Backend Requirement

This mobile app requires the MemeVerse web application backend to be running.

For Android Emulator, use:

```text
http://10.0.2.2/memeverse/
```
## Local Setup
